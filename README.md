# To-Do List

web progg лаба 2, список задач на чистом js. Можно добавлять задачи со сроком, менять, удалять, отмечать сделанные и перетаскивать мышкой. Есть поиск по названию и дате, фильтр и сортировка по дате, все хранится в localStorage.

used: HTML, CSS, JS
